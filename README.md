# COFFEE DNA

모리티아·사이드템포 매장용 10문항 커피 취향 테스트입니다. GitHub Pages에 올리는 정적 사이트이며, 응답은 구글 스프레드시트에 기록합니다.

## 주소

| 주소 | 용도 |
|---|---|
| `/` | 매장 선택 (모리티아 / 사이드템포) |
| `/mauritia/`, `/sidetempo/` | 각 매장의 테스트 |
| `/<매장>/result/<유형코드>/` | 유형별 공유 페이지. 카드·추천 메뉴와 링크 미리보기 정보가 들어 있습니다 |

주소 뒤에 붙이는 표시:

- `?kiosk=1` : 그 기기를 매장 태블릿 모드로 고정합니다(`?kiosk=0`으로 해제). 한 번만 열면 기억합니다.
- `?ch=insta` : 인스타 링크로 들어온 테스트임을 시트의 `유입`에 남깁니다. `share`(공유 페이지의 "나도 테스트하기"), `qr`(매장 QR)은 사이트가 자동으로 붙입니다.

## 두 가지 모드

| | 온라인 (기본) | 매장 태블릿 (`?kiosk=1`) |
|---|---|---|
| 무조작 초기화 | 없음 | 문항 20초 / 결과 60초 뒤 알림, 10초 뒤 복귀 |
| 결과 화면 | 결과 공유하기 · 카드 이미지 저장 | QR로 내 휴대폰에 가져가기 |
| 전체화면 · 브랜드 선택 | 숨김 | 표시 |
| 시트의 `채널` | 온라인 | 매장 |

## 응답 기록

테스트 한 번이 시트의 `응답` 탭에 한 줄로 들어갑니다.

| 상황 | 보내는 시점 | 상태 / 종료 사유 |
|---|---|---|
| 끝까지 완료 | 결과가 나올 때 | 완료 / 완료 |
| 문항 중 "처음으로" | 누를 때 | 미완료 / 처음으로 |
| 문항 중 무조작 | 자동 복귀할 때 | 미완료 / 시간 초과 |
| 문항 중 브라우저 종료·새로고침 | 다음에 사이트가 열릴 때 | 미완료 / 페이지 이탈 |

미완료에는 멈춘 문항 번호와 그때까지의 응답이 함께 기록됩니다. 전송에 실패한 응답은 태블릿에 보관했다가 다음 전송 때 다시 보냅니다. 같은 ID는 한 줄만 유지합니다.

무조작 시간은 `src/shared/config.ts`에서 바꿉니다.

## 구글 시트 연결

1. 새 구글 스프레드시트를 만듭니다.
2. 확장 프로그램 > Apps Script를 열고 `google-sheet/Code.gs`의 내용을 붙여 넣은 뒤 저장합니다.
3. 함수 목록에서 `setup`을 골라 실행하고 권한을 허용합니다. `응답`, `통계` 탭이 생깁니다.
4. 배포 > 새 배포 > 유형 "웹 앱", 실행 "나", 액세스 권한 "모든 사용자"로 배포합니다.
5. 나온 웹 앱 URL(`…/exec`)을 `src/shared/config.ts`의 `SHEET_URL`에 넣고 다시 배포합니다.

`Code.gs`를 고친 뒤에는 배포 관리에서 새 버전으로 다시 배포해야 반영됩니다. `통계` 탭의 노란 칸(시작일·종료일)을 바꾸면 기간별로 볼 수 있습니다.

## 개발과 배포

Node.js 22 이상. `npm ci`, `npm run dev`, `npm run build`.

`main` 브랜치에 올리면 `.github/workflows/deploy.yml`이 빌드해서 GitHub Pages에 배포합니다. 저장소 Settings > Pages > Source를 "GitHub Actions"로 설정해야 합니다.

## 구성

- `src/mauritia`, `src/sidetempo` : 매장별 화면·문항(`quiz-data.json`)·채점(`quiz.ts`)·스타일
- `src/shared` : 시트 전송(`survey.ts`), 무조작 알림(`idle.tsx`), 전체화면, 설정
- `public/<매장>/type-cards` : 16유형 결과 카드
- `public/<매장>/og` : 링크 미리보기 이미지. 카드를 바꾸면 `python scripts/make-og-images.py`로 다시 만듭니다
- `vite.config.ts` : 유형별 공유 페이지를 빌드 때 생성합니다. 저장소 이름이나 도메인이 바뀌면 `SITE_URL`을 고칩니다
- 한글 서체 SUIT (SIL OFL, `src/*/assets/OFL.txt`)

기존 Codex 사이트(`mauritia-coffee`, `sidetempo-coffee`)의 화면과 채점을 그대로 옮겼고, 서버 저장과 관리자 페이지는 시트 기록으로 대체했습니다.
